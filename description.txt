Project Name: Inverted Search
Description: An inverted search project in data structures involves creating a system that enables efficient searching of text 
             documents by indexing the words within them. This system utilizes an inverted index, a data structure that maps each 
             unique word (or term) to the documents in which it appears. The primary goal is to facilitate quick retrieval of documents 
             based on keyword searches.In the implementation, the project typically starts by reading and processing a collection of 
             text files. Each word is extracted, normalized, and indexed alongside its corresponding document identifier. The index may 
             also store additional information, such as the frequency of the word within each document or its position.
             When a user performs a search query, the inverted index allows the system to quickly locate all documents containing the 
             specified keywords, significantly reducing search time compared to scanning through each document linearly.  
             Overall, an inverted search project enhances the searchability of large datasets, making it an essential component in 
             applications like search engines, document management systems, and information retrieval systems.
