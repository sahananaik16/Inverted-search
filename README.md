# Inverted-search
The Inverted Search project in C is a file-based indexing and search system that uses a hash table to implement an inverted index for efficient keyword-based search operations across multiple text files. It begins by validating the provided input files—ensuring they exist, have the correct .txt extension, and contain content. Valid files are added to the list and processed to extract words. Each word is stored in a hash table along with metadata such as the number of files it appears in, the names of those files, and the frequency of the word in each file. The project offers a user-friendly menu-driven interface with options to create the database, display its contents, search for specific words, save the database to a file, update it from a saved file, and exit the program. This efficient structure enables rapid word lookup without scanning every file during a search. The data can be saved in a structured format using delimiters for future use or restoration. This project demonstrates the practical use of data structures like linked lists and hash tables, string manipulation, file handling, and command-line input, making it a foundational example of information retrieval systems similar to search engines.
